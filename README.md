# ASL Hangamn

## Description 
ASL Hangamn is a gamified full-stack web application that gamifies the process of learning and practicing the American Sign Language. The application provides two modes (learn and play) and multiple categories to practice with. Learn mode displays an image of the hand gesture and guides the user to learn the sign. Play mode provides a hands-off approach, allowing the users to test their skills. To enhance the learning experience and keep users engaged, there is a global leaderboard to track engagement and points earned. 

## Tech Stack
-  Computer Vision (OpenCV, Mediapipe Hands)
-  Machine Learning (MLP Neural Network, Scikit-learn, Numpy, Pandas)
-  Frontend: Next.js, TailwindCSS
-  Backend + Database: FastAPI, PostgreSQL
-  Deployment: AWS (RDS, Elastic Beanstalk), Docker, Vercel (frontend)
